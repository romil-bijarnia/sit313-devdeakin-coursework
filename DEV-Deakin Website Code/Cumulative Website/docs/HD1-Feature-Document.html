Student: Romil Bijarnia

Project: DEV@Deakin cumulative React application

Feature Summary

The HD extension adds advanced features to DEV@Deakin beyond the standard Pass, Credit, and Distinction tasks. The app includes secure collaboration messaging, a two-factor authentication demo, and an interactive tutorial library with views and ratings.

Secure Collaboration Room

The collaboration room lets users submit project updates and stores them with a checksum. This demonstrates secure communication concepts, persistent user interaction, message history, and reusable form handling.

Two-Factor Authentication Demo

The two-factor authentication feature generates a six-digit code, accepts user input, verifies the code, and reports success or failure. This demonstrates authentication state, validation, security-oriented UI, and controlled inputs.

Tutorial Videos With Views and Ratings

The tutorial library displays uploaded lesson-style cards and lets users increase view counts and submit ratings. The feature demonstrates mapped React data, reusable media cards, local persistence, and interactive feedback.

Advanced React Concepts Used

The app uses React Router, reusable components, conditional rendering, controlled forms, browser persistence, stateful filters, array mapping, file upload previews, validation, and component composition across multiple routes.
